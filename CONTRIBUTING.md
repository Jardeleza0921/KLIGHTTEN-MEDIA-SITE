# Contributing

Thanks for helping improve the KLIGHTTEN MEDIA public website.

## Principles

Changes should preserve:

- Linux-first positioning
- lightweight static architecture
- the five canonical KLIGHTTEN themes
- current KLIGHTTEN MEDIA branding
- responsive and accessible behavior
- no advertising or analytics by default
- accurate Privacy / Terms / OAuth documentation

## Development

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080/`.

## Before a Pull Request

Check Home, Download, Privacy, Terms, OAuth, Contact, 404, mobile layout, all five themes, and internal links.

Do not commit credentials, tokens, cookies, private URLs, personal paths, or unrelated generated files.

## Commit Style

```text
fix: correct mobile navigation
docs: update OAuth disclosure
style: refine Neon-Arcade cards
release: publish KLIGHTTEN MEDIA 3.1
```
