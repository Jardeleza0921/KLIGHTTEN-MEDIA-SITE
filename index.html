Version 3.1

A clearer Linux media workspace.

Version 3.1 separates Music, YouTube, Local files and Anime into focused workspaces, adds a persistent YouTube browser, and standardizes KLIGHTTEN's Linux keyboard and theme system.

Music

An ArchiveTune-inspired music workflow for songs, artists, albums, playlists, favorites, history and queue.

Local

One clean Local workspace for music and video files stored directly on your Linux computer.

ani-cli

A normal keyboard-driven in-app terminal with native MPV handoff for episode playback.

YouTube Browser

A persistent Qt WebEngine/Chromium browser for normal YouTube videos, channels, playlists, searches and account pages.

Local Converter

Convert files already on your computer to MP3 or MP4 with FFmpeg. No downloader/ripping module is included.

Five Canonical Themes

Dark-Mint, Neon-Arcade, Black-White, Crimson-Red and Cream Coffee — the five canonical KLIGHTTEN themes.

Playback routing

Automatic where it should be.

You no longer need to choose between several local player engines. KLIGHTTEN routes media to the compatible playback path automatically.

KLIGHTTENMusic/Local/ani-cli → MPV • YouTube website → Chromium • Conversion → FFmpeg
Audio libraryMPV first, with an emergency local-audio fallback if MPV is unavailable.
Movies & video filesNative MPV video surface integrated with KLIGHTTEN’s Now Playing view.
Anime playbackani-cli stays keyboard-driven while video hands off to the same MPV media path.
YouTubeRemains in Chromium/Qt WebEngine so YouTube playback uses the browser-compatible path.

Google data

Optional and read-only.

You can use KLIGHTTEN MEDIA without connecting Google. If you choose to connect YouTube, the app requests read-only access for the connected-account features shown inside the app.

Read OAuth disclosurePrivacy policy
User-facing account dataChannel/account identity, playlists, subscriptions and liked videos are shown only for app features you use.
Local token storageAuthorization tokens are stored on your device so the connected account can remain signed in.
No write actionsThe current scope does not upload, delete, comment, rate or edit YouTube content.
