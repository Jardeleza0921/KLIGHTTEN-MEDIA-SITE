Privacy Policy

KLIGHTTEN MEDIA is designed as a desktop-first, local-first application.

Effective August 23, 2026Version 2.7

1. Overview

KLIGHTTEN MEDIA is a Linux desktop media application. Most app state is stored on the user's computer. The public website does not include advertising or analytics scripts by default.

2. Local application data

The app may store settings, profile preferences, selected themes, queue state, favorites, history, local library metadata, video-library metadata, plugin settings, and other application state under the user's local KLIGHTTEN configuration directory.

3. Local media

When you select music, video, or folders, KLIGHTTEN MEDIA reads the paths and metadata required to show and play those files. Local media is not uploaded by this website or by the normal local-library workflow.

4. Optional Google/YouTube data

If you connect Google/YouTube, KLIGHTTEN MEDIA requests the read-only YouTube scope documented on the OAuth & Data Use page. Connected-account information is used to provide the account features you request in the application.

5. OAuth tokens

Authorization tokens are stored locally on the user's device so the account can remain connected. Tokens are not intended to be published, included in releases, or exposed on this website.

6. ani-cli and third-party services

ani-cli and other optional integrations can access third-party websites or services according to those projects' own behavior and terms. KLIGHTTEN MEDIA does not control the privacy practices of those third parties.

7. Converter Studio

Converter Studio processes files already available on the user's computer with FFmpeg. The current KLIGHTTEN MEDIA build does not include the former experimental Direct Downloader or Pytube downloader module.

8. Sharing and sale of data

KLIGHTTEN MEDIA does not sell Google user data or local media data to advertisers. The website contains no advertising scripts by default.

9. Retention and deletion

You can remove local application state from KLIGHTTEN's configuration directory. You can disconnect a Google account inside the app and revoke its authorization through Google. Automatic upgrade cleanup removes known obsolete KLIGHTTEN downloader/plugin state but is designed not to delete user media or OAuth/account data.

10. Security

No desktop application can guarantee absolute security. Users should keep their operating system, browser/Qt components, MPV, FFmpeg and KLIGHTTEN dependencies updated and should not share OAuth token files.

11. Website data

This static GitHub Pages-ready website does not set advertising or analytics cookies. The theme switcher saves only the selected website theme in your browser's local storage.

12. Changes

This policy may be updated when KLIGHTTEN MEDIA adds or removes features, integrations, cloud services, analytics, scopes or data-handling behavior. The published policy should always describe the actual released application.

13. Contact

Support contact will be configured before production verification.
