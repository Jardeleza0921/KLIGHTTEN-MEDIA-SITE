KLIGHTTEN MEDIA • 2.7
Version 2.7

Polished around the controls you actually use.

The current build simplifies playback around MPV, separates local video into its own library, removes the experimental downloader stack, and gives media controls a consistent icon and keyboard system.

Local Audio

Automatic MPV playback for your music library with queue, favorites, shuffle, repeat, volume boost and sound presets.

Local Videos

A dedicated Videos tab for MP4, MKV, WebM, MOV, AVI, M4V, MPEG, TS, FLV and WMV files.

ani-cli

A normal keyboard-driven in-app terminal with native MPV handoff for episode playback.

YouTube Playback

Qt WebEngine/Chromium playback with optional Google account connection for read-only YouTube features.

Local Converter

Convert files already on your computer to MP3 or MP4 with FFmpeg. No downloader/ripping module is included.

Four Themes

Neon Arcade, Classic Green, Black + White and Redhat. Use the theme switcher above to preview the same visual families on this site.

Playback routing

Automatic where it should be.

You no longer need to choose between several local player engines. KLIGHTTEN routes media to the compatible playback path automatically.

KLIGHTTENYouTube → Chromium • Local audio/video → MPV • ani-cli → MPV

Anime playbackani-cli stays keyboard-driven while video hands off to the same MPV media path.
YouTubeRemains in Chromium/Qt WebEngine so YouTube playback uses the browser-compatible path.

Google data

Optional and read-only.

You can use KLIGHTTEN MEDIA without connecting Google. If you choose to connect YouTube, the app requests read-only access for the connected-account features shown inside the app.

No write actionsThe current scope does not upload, delete, comment, rate or edit YouTube content.
