Install

Extract the ZIP, then run the setup script once on a new installation.

cd KLIGHTTEN_MEDIA
chmod +x setup.sh run.sh diagnose.sh
./setup.sh
./run.sh

Updating an existing 2.6.1+ install

Replace the application folder with the new build. Your user configuration remains under ~/.config/klightten-media/.

chmod +x run.sh diagnose.sh
./run.sh
Automatic cleanup: current builds remove obsolete KLIGHTTEN downloader/Pytube leftovers and generated caches without deleting your media, converted files, OAuth accounts, library state, favorites, queue or history.
